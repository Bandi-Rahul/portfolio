Drone-Based Aerial Mapping

LiDAR-powered UAV system for high-precision 2D terrain mapping and surveying

Robotics LiDAR IoT Python Embedded C

Overview

Goal

Develop a cost-effective aerial mapping solution using drone technology and LiDAR sensors

Innovation

Custom integration of YD Lidar X2 sensor with quadcopter platform for real-time terrain scanning

Outcome

Achieved 95% test success rate with ±2% accuracy in 360° terrain mapping

Project Summary

Designed and built an autonomous drone equipped with YD Lidar X2 sensor capable of generating high-precision 2D point clouds for terrain mapping. The system combines custom hardware integration with Python-based data processing to deliver accurate aerial surveys for applications in agriculture, forestry, construction, and disaster management.

Key Features

360° LiDAR Scanning

Full panoramic coverage with 0.36° resolution at 5000Hz scan rate

Real-Time Point Cloud

Live 2D terrain data generation and visualization during flight

Custom Integration

Arduino-based sensor control with KK2.1.5 flight controller

Python Processing

Data analysis using NumPy, Pandas, and Matplotlib libraries
